## Things to know
- Claude Code is the development tool. Its context is `CLAUDE.md` (which
  imports `RULES.md`) plus the path-specific rules in `.claude/rules/`.
  There is no Cursor configuration; do not add one.
- The project sits at the repo root, not in `hydrately/` (ADR-009).
- The design system overrides the guide's placeholder colours (ADR-010).
- Settings appear in the popup tab and the options page; both use
  `components/SettingsForm.vue` (ADR-011).
- Defaults follow the design: breaks on (20-20-20), quiet hours
  20:00 to 08:00, chime on (ADR-021). Change them in
  `utils/constants.ts` if first-run reminders feel too frequent.
- Settings stay in storage.sync on purpose: cross-device sync is wanted
  (ADR-026).
- Storage writes go through a Web Lock; keep new writes inside
  `exclusive()` in `services/storage.ts` (ADR-024).
- TypeScript is pinned to 6.0 because typescript-eslint does not support
  TypeScript 7 yet.
- `public/` assets are generated by `npm run assets` and committed.
